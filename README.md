## 快速开始

为 Grok Bot 安装 claude-mem：

```bash
npx claude-mem install --ide grok-bot
```

Grok Bot 没有宿主钩子，因此我们通过监听聊天日志文件来工作。默认使用 CMEM Pro（托管记忆）。本地观察器为可选开启：`--provider host`。安装此插件不会安装 Cursor。

**感知推送试点（LFG + Orifice）：** 关键观察（`decision`、`bugfix`、`security_alert`、`sensitive`）会以带日期的 `- YYYY-MM-DD [awareness] …` 行追加到该 bot 的 `memory/log/YYYY-MM.md` 中。Grok Bot 本来就会从磁盘重新读取该日志。此功能不会写入 `profile.md`、用户记忆或项目记忆。可通过 `CLAUDE_MEM_GROK_BOT_AWARENESS_ENABLED=false` 关闭。

使用一条命令安装：

```bash
npx claude-mem install
```

安装程序会先完成所有基础设置，然后提示你在浏览器中登录 claude-mem（邮箱魔法链接，无需绑卡）。登录会为你的账户分配一个记忆密钥，并解锁带 **30 天免费试用** 的 **claude-mem 观察器**：记忆运行于套餐之外，因此你最多可从套餐中获得 100% 的额外用量。免费试用结束后，除非你订阅，否则记忆会自动回退到你的 Anthropic 套餐。登录后，你可以选择记忆提供者——claude-mem 观察器、你自己的 OpenRouter 或 Gemini 密钥，或者你的 Anthropic 套餐。

想跳过登录？传入明确的 `--provider` 参数、设置 `CLAUDE_MEM_ONLINE_OPTIN=false`，或在 CI / 非交互式 shell 中运行——安装程序会在不产生任何账户交互的情况下完成安装。

或者为 OpenCode 安装：

```bash
npx claude-mem install --ide opencode
```

适用于 OpenCode 1.3.4 及以上版本（含 OpenCode 2）。安装后请重启 OpenCode。

或者为 **T3 Code**（Codex 与 Claude Code 提供者）安装：

```bash
npx claude-mem install --ide t3code
```

安装程序会探测 T3 Code 已启用的提供者，在其配置的 home 目录中注册原生 Claude-Mem 插件，并支持 T3 托管的 Codex。请重启 T3 Code，在提示时信任该提供者的钩子，并开启一个新会话。请参阅 [T3 Code 集成指南](https://docs.claude-mem.ai/t3code-integration) 了解自定义服务器设置、状态及卸载方式。

或者为 Antigravity CLI 安装（[设置指南](https://docs.claude-mem.ai/antigravity-cli/setup)）：

```bash
npx claude-mem install --ide antigravity
```

或者为 OMP（Oh My Pi）安装：

```bash
npx claude-mem install --ide omp
```

或者安装原生的 Pi 扩展或 DeepSeek Harness 插件：

```bash
npx claude-mem install --ide pi
npx claude-mem install --ide dsh --dsh-profile tui
```

Pi 与 DeepSeek Harness 使用 worker 运行时。请参阅 [原生 harness 设置](https://github.com/thedotmack/claude-mem/blob/main/docs/native-harness-integrations.md) 了解捕获、召回与故障排查。

或者在 Claude Code 内通过插件市场安装：

```bash
/plugin marketplace add thedotmack/claude-mem

/plugin install claude-mem
```

重启 Claude Code。以往会话的上下文将自动出现在新会话中。

> **注意：** Claude-Mem 也发布在 npm 上，但 `npm install -g claude-mem` 只安装 **SDK / 库**——它不会注册插件钩子，也不会设置 worker 服务。请始终通过 `npx claude-mem install` 或上述的 `/plugin` 命令来安装。

### 🦞 OpenClaw 网关

通过一条命令，将 claude-mem 作为持久化记忆插件安装到 [OpenClaw](https://openclaw.ai) 网关上：

```bash
curl -fsSL https://install.cmem.ai/openclaw.sh | bash
```

安装程序会处理依赖、插件设置、AI 提供者配置、worker 启动，以及可选的实时观察推送（至 Telegram、Discord、Slack 等）。详情请参阅 [OpenClaw 集成指南](https://docs.claude-mem.ai/openclaw-integration)。

**核心特性：**

- 🧠 **持久化记忆** - 上下文在不同会话间得以保留
- 📊 **渐进式披露** - 分层记忆检索，并可视化 token 成本
- 🔍 **智能搜索（默认）** - 通过三步 mem-search 技能查询你的项目历史
- 🖥️ **本地 My Work** - 启动时会打印 worker URL，其中包含实时请求、进度、人工交接以及已保存的审查队列。[指南](https://docs.claude-mem.ai/usage/my-work)。记忆、会话与设置保留在 `/viewer`。
- 👥 **TeamBrain** - My Work 旁边一个可选的共享工作区，带有真实的团队工作列表、成员归属与关联发现。每个人自行选择分享哪些内容；个人请求与审查笔记保持独立。[创建团队](https://cmem.ai/teambrain/start)。
- 💻 **Claude Desktop 技能** - 从 Claude Desktop 对话中搜索记忆
- 🔒 **隐私控制** - 使用 `<private>` 标签将敏感内容排除在存储之外
- 🖼️ **截图（可选，默认关闭）** - 将工具截图转换后的副本保存在 `~/.claude-mem/media-v1/` 下，仅在开启云同步时上传至 cmem.ai，并且仅在单独启用图像推理时才发送给观察器模型（[详情](https://docs.claude-mem.ai/configuration#screenshots-and-images-opt-in)）
- ⚙️ **上下文配置** - 精细控制注入哪些上下文
- 🤖 **自动运行** - 无需人工干预
- 🔗 **引用** - 通过 worker API 用 ID 引用过往观察，或在 Web 查看器中查看全部

## 工作原理

**核心组件：**

1. **生命周期钩子** - SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop、SessionEnd。每个钩子都是一条无 shell 的命令 `claude-mem hook claude-code <event>`，由安装程序放到 PATH 上的一个小型启动器运行
2. **智能安装** - 带缓存的依赖检查器（`claude --init` / `--maintenance` 上的 Setup 钩子，外加 `npx claude-mem install` / `repair`）
3. **Worker 服务** - 由 Bun 管理的本地 HTTP API，带 Web 查看器 UI 与搜索端点
4. **SQLite 数据库** - 存储会话、观察与摘要
5. **mem-search 技能** - 带渐进式披露的自然语言查询
6. **Chroma 向量数据库** - 用于智能上下文检索的混合语义 + 关键词搜索

详情请参阅 [架构概览](https://docs.claude-mem.ai/architecture/overview)。

## MCP 搜索工具

Claude-Mem 通过 **4 个 MCP 工具** 提供智能记忆搜索，遵循省 token 的 **三层工作流模式**：

**三层工作流：**

1. **`search`** - 获取带 ID 的紧凑索引（约 50-100 tokens/结果）
2. **`timeline`** - 获取感兴趣结果周边的时间线上下文
3. **`get_observations`** - 仅为筛选出的 ID 获取完整详情（约 500-1,000 tokens/结果）

**工作原理：**
- Claude 使用 MCP 工具搜索你的记忆
- 先用 `search` 获取结果索引
- 用 `timeline` 查看特定观察周边的情况
- 用 `get_observations` 为相关 ID 获取完整详情
- 先筛选再获取详情，可节省 **约 10 倍 token**

**可用的 MCP 工具：**

1. **`search`** - 通过全文查询搜索记忆索引，可按类型 / 日期 / 项目过滤
2. **`timeline`** - 获取特定观察或查询周边的时间线上下文
3. **`get_observations`** - 按 ID 获取完整观察详情（始终批量传入多个 ID）

**使用示例：**

```typescript
// 第 1 步：搜索索引
search(query="authentication bug", type="bugfix", limit=10)

// 第 2 步：查看索引，确定相关 ID（如 #123、#456）

// 第 3 步：获取完整详情
get_observations(ids=[123, 456])
```

详细示例请参阅 [搜索工具指南](https://docs.claude-mem.ai/usage/search-tools)。

## 系统要求

- **Node.js**: 20.0.0 或更高
- **Claude Code**: 支持插件的最新版本
- **Bun**: JavaScript 运行时与进程管理器（缺失时自动安装）
- **uv**: 用于向量搜索的 Python 包管理器（缺失时自动安装）
- **SQLite 3**: 用于持久化存储（已内置）

### Windows 安装说明

如果你看到类似错误：

```powershell
npm : The term 'npm' is not recognized as the name of a cmdlet
```

请确保已安装 Node.js 和 npm，并已加入 PATH。请从 https://nodejs.org 下载最新的 Node.js 安装程序，安装后重启终端。

Claude Code 钩子不需要 Git Bash。每个钩子直接运行 `claude-mem`，而 `npx claude-mem install` 会将该启动器放到 `%LOCALAPPDATA%\claude-mem\bin\claude-mem.exe`，并把该文件夹加入你的用户 Path。完成后请重启终端或 IDE，以便 Claude Code 读取新的 Path。如果钩子报错 `Executable not found in $PATH: "claude-mem"`，请运行 `npx claude-mem doctor` 并参阅 [故障排查](https://docs.claude-mem.ai/troubleshooting#claude-mem-command-not-found-in-hooks)。

## 配置

设置保存在 `~/.claude-mem/settings.json`（首次运行时自动创建并填入默认值）。可在此配置 AI 模型、worker 端口、数据目录、日志级别与上下文注入设置。

要在 Claude Code 与 Codex 的 SessionStart 上下文中包含来自每个 harness 的观察，请在该文件中设置 `"CLAUDE_MEM_SESSION_START_INCLUDE_ALL_SOURCES": "true"`，或在查看器设置中启用 **会话开始时包含全部来源**。默认值为 `"false"`，即仅将启动上下文限制在当前 harness。所选来源仍需遵守观察数量上限。

所有可用设置与示例，请参阅 **[配置指南](https://docs.claude-mem.ai/configuration)**。

### 模式与语言配置

Claude-Mem 通过 `CLAUDE_MEM_MODE` 设置支持多种工作流模式与语言。

该选项同时控制：
- 工作流行为（如 code、chill、investigation）
- 生成观察所使用的语言

#### 如何配置

编辑你的设置文件 `~/.claude-mem/settings.json`：

```json
{
  "CLAUDE_MEM_MODE": "code--zh"
}
```

模式定义在 `plugin/modes/` 中。要在本地查看所有可用模式：

```bash
ls ~/.claude/plugins/marketplaces/thedotmack/plugin/modes/
```

#### 可用模式

| 模式 | 说明 |
|------------|-------------------------|
| `code` | 默认英文模式 |
| `code--zh` | 简体中文模式 |
| `code--ja` | 日文模式 |

特定语言的模式遵循 `code--[lang]` 形式，其中 `[lang]` 是 ISO 639-1 语言代码（例如 `zh` 代表中文、`ja` 代表日文、`es` 代表西班牙文）。

> 注意：`code--zh`（简体中文）已内置——无需额外安装或更新插件。

#### 更改模式后

请重启 Claude Code 以应用新的模式配置。
